pulsar catalog: class data that tells Pulsar what a symbol is.

A catalog says "this call is a query / blocking / a log / reads ambient state". It never makes
a finding by itself. Findings come only from RULES, which a pack or the repo turns on.

USAGE
  pulsar catalog check <file.toml>...   parse and validate; exit 2 with the reason on error
  pulsar catalog list [--repo dir]      catalogs in effect: id, scope, sha256, why active

WHERE CATALOGS LIVE
  lane   shipped in the binary, always on for that language (js-globals)
  pack   shipped in the binary, switched on by evidence in the repo (effect, platform-node)
  repo   your own: <repo>/.pulsar/catalogs/<name>.toml, always on for that repo
Every catalog's sha256 is part of the printed policy fingerprint, so changing one is visible.

FILE FORMAT  (TOML; format = "pulsar-catalog 0")
  Top level keys, all strict (an unknown key is an error):
    format    = "pulsar-catalog 0"
    id        = "my-repo"              lowercase letters, digits, dashes
    scope     = "repo"                 lane | pack | repo
    activate  = ["dep:effect"]         scope "pack" only. Any match switches the pack on:
                                         dep:<package>          package.json dependency
                                         import:<specifier glob> an import in the repo
                                         file:<base name>       a tracked file of that name (wrangler.toml)
    sources   = ["what you checked"]   free text, kept as evidence
  Arrays of inline tables. ONE ENTRY PER LINE, SORTED, no duplicates, or the file is rejected:

    classes = [                        every class you use must be declared here
      { class = "query", id = 1, rule = "my-repo/query" },
    ]                                  id: 1-15 are the fixed classes below, repo classes start at 1000
                                       rule: the rule id reported with any finding that uses the class

    symbols = [                        sorted by (sym, via, use, ver)
      { sym = "pg#Pool.query", class = "query", ver = "1", at = "pg@8:docs/pool.md:12", doc = "Runs a query." },
      { sym = "db#sql", class = "query", via = "yield", use = "tag", ver = "1", at = "...", doc = "..." },
    ]
      sym   "<module specifier>#<export path>", e.g. "node:fs#readFileSync", "global#Date.now"
      class a declared class
      via   which event at a site counts (default "call"):
              call          a call of sym
              ref           any reference to sym
              yield         a use of the value bound by `yield* sym`
              result        a use of the value returned by calling sym
              yield-result  a use of the value bound by `yield* sym(...)`
              read          a property read
              new           a construction
      use   with yield/result/yield-result, which use counts: tag (a tagged template yielded
            or awaited where it is written; one stored or passed on is built, not run), call,
            member:<name> (a method call), member:* (any method); with new: noargs
      ver   a label for the library version or runtime this entry is true for ("3", "4", "node", "js")
      at    where the justification lives (file:line); doc  the text that justifies the class

    handlers = [ { sym, arg, ver, at, doc } ]        error handlers; arg = last-fn | object-fns
    entries = [ { sym, shape, kind, names?, ver, at, doc } ]   entry points (functions called from outside);
                                       sorted by (sym, shape, kind, ver); kind = EP kind 1-6: 1 request handler,
                                       2 object method, 3 RPC method, 4 alarm/scheduled, 5 queue consumer,
                                       6 HTTP API handler; shape = subclass-methods (methods of a class that
                                       extends sym) | default-export-fns (sym is empty: the default export or
                                       its function properties) | callback-args (function arguments of calls
                                       to sym); names narrows subclass-methods and default-export-fns
    wrappers = [ { sym, ctx, label, ver, at, doc } ] function arguments get ctx bits;
                                                     label = none | first-string
    services = [ { sym, default, ver, at, doc } ]    default = true: always provided
    layers   = [ { sym, builds, ver, at, doc } ]     builds = array of service syms
    aliases  = [ { from, to } ]                      prefix rewrites, longest first
    rules    = [ { id, class, ctx_any, ctx_none, says, ver, at, doc } ]
      A call site whose callee is in `class`, in a context where (ctx_any == 0 or a ctx_any bit
      is set) and no ctx_none bit is set, is a finding of rule `id`. A rule is on only when its
      catalog is active, and only if policy.toml does not disable it.
    fanouts  = [ { id, class, edges, none, says, ver, at, doc } ]
      Fan-out (N+1 and kin): a call at loop depth > 0 whose ctx has no bit of `none`, and that reaches
      a call of a symbol of `class` within `edges` call edges (0 = the call itself), is a finding of
      rule `id`. A call inside an iterator callback is the callback's own function at depth 0.
    konsts   = [ { id, class, pos, says, ver, at, doc } ]
      Constant argument: a call of a symbol of `class` whose argument `pos` (0-based) is a constant.
    hots     = [ { id, lane, base, depth, says, ver, at, doc } ]
      Hot path: a finding of rule `base` whose function an entry point (`entries`) reaches within
      `depth` call edges. lane = sql (base is an `sql.*` rule) | fanout | konst (base is a `fanouts`
      or `konsts` id). The rule is on only when its base rule is on: an sql.* base needs policy.toml
      `[rules] enable`. Ids are unique across rules, fanouts, konsts, hots and growths; each list is sorted by id.
    growths  = [ { id, depth, says, ver, at, doc } ]
      Unbounded growth: a SELECT with no LIMIT whose filter binds no key of the table, on a table
      that code an entry point reaches within `depth` call edges inserts into. Needs the repo's
      schema (.sql files) to be complete; with a partial schema it reports nothing and says so.
    edges    = [ { id, all, none, target_all, target_none, says, ver, at, doc } ]
      Call edge: a call to a repo function from a site whose ctx has every bit of `all` and none of
      `none`, where the callee's own ctx has every bit of `target_all` and none of `target_none`.
    modules  = [ { id, all, none, also_all, also_none, says, ver, at, doc } ]
      Module: a file holding a function whose ctx has every bit of `all` and none of `none`, and a
      function whose ctx has every bit of `also_all` and none of `also_none`. A function's ctx is
      the call-site ctx in force where it is defined (the bits below, without 4 and 64).
      Edge and module ids share that one id space; each list is sorted by id.

FIXED CLASS IDS
  1 query  2 blocking  3 log  4 error-erasing  5 runtime-escape  6 fork
  7 resource-acquire  8 ambient-read  9-13 reserved  14 promise-style  15 exception-style
  (repo classes: 1000 and up)

CTX BITS (call sites)
  1 inside an async function   2 inside an Effect generator or Effect.fn   4 inside a test
  8 file in effect_only scope  16 file in boundary scope  32 inside an interop callback
  (2 and 32 come from a pack's wrappers; 8 and 16 only from the repo's policy)
  128 directly in the body of a function a pack wrapper takes: that function's own frame only,
      never a function nested in it (a callback inside an Effect.gen body does not have it)

SYNTAX SYMBOLS  sym = "syntax#<name>": a language construct, emitted only where an active rule could fire
  await (also for await)  async-fn (in the async function itself)  throw  try
  member.then  member.catch  member.finally  (a method call on a value that is not an imported symbol)

MINIMAL REPO CATALOG  (.pulsar/catalogs/db.toml)
  format = "pulsar-catalog 0"
  id = "db"
  scope = "repo"
  sources = ["internal docs"]
  classes = [
    { class = "query", id = 1, rule = "db/query" },
  ]
  symbols = [
    { sym = "./db#run", class = "query", ver = "1", at = "src/db.ts:3", doc = "Runs a SQL query." },
  ]

Run `pulsar catalog check .pulsar/catalogs/db.toml` before committing.
